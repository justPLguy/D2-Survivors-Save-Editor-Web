Web Editor Guide — how to use this version

Quick instructions for the browser version. The layout and workflow differ slightly from the Windows EXE editor.

1. Load your save

  1. Paste a save code beginning with D2S1: into the top box and click Load Save Code, or use Load from File….
  2. Keep an untouched copy of your original save before editing.
  3. To change gold, enter the new amount and click Apply Gold.

2. Character & Mercenary

Open this tab and select the character class you want to edit. If the save contains an assigned mercenary, you can select it here too. The selected character determines which equipment and skill build you see in the other tabs.

3. Items & Modifiers

  1. Open Items & Modifiers after selecting a character.
  2. Choose Equipped or Inventory as the item source.
  3. Select an item, edit the available modifier fields, and use the controls shown for the selected item to apply the changes.

4. Belt & Potions

  1. Select a character class in Character & Mercenary.
  2. Open Belt & Potions. The editor reads the four existing belt slots from that character.
  3. For each slot, choose Potion or Rejuvenation and set the quantity from 0 to 3. Quantity 0 empties the slot.
  4. Click Apply Belt Changes, confirm the summary, then open Preview & Export and generate the save code.

Potion editing only works when compatible belt data already exists in the save. The editor does not create a missing belt automatically. The game may enforce its own stack limits.

5. Character Skills

  1. Select the class in the skill filter.
  2. Use Search, Type, Tree, and Show to find a skill. “Present” means the skill already exists in the save.
  3. Select a skill, set its new base level, and click Add to change list.
  4. Review the staged list, then click Apply All Changes. Use Undo last applied if needed.

Base skill level is separate from bonuses granted by equipment. The editor only changes existing skills; gear bonuses are not written into base levels.

6. Preview & Export

  1. Open Preview & Export and click Preview Changes to review the actual edited values.
  2. Click Generate Save Code.
  3. Use Copy output or Save Output to File… to export the generated save.
  4. Load the generated code/file into the game and verify the result.

Reset and safety

  • Reset Changes clears the current editing session; use it only when you intend to discard your edits.
  • Generate and test the save using a copy first, especially after changing skills.
  • If something looks wrong, return to your untouched original save rather than overwriting it.
Leaderboard warning: modified saves may flag your character; runs made with an edited character will not count toward leaderboards. Always keep an untouched backup.

Web version vs. EXE: this version runs in your browser. Skill changes are staged first and must be applied with Apply All Changes; then you still need to generate and export the save. The Windows EXE may organize these steps differently. Always use Preview Changes and keep a backup.
