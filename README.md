## 🌐 Open the Editor

**[Launch D2 Survivors Save Editor →](https://justplguy.github.io/D2-Survivors-Save-Editor-Web/)**

Open the editor directly in your browser on Windows, Mac, Android, or other supported devices.

No installer, Python environment, or desktop application is required.

## ✨ Features

- 💰 **Gold Editor** — change your character's gold.
- 🛡️ **Equipment Editor** — browse equipped items and inventory.
- ⚔️ **Item Modifiers** — edit supported item modifier values.
- 🧙 **Character Classes** — browse available character classes.
- 🏹 **Mercenary Equipment** — inspect and edit supported mercenary items.
- 🔮 **Skills & Passives** — search, filter, and stage skill level changes.
- 🔍 **Change Preview** — review differences before exporting.
- 💾 **Save Export** — generate a modified save code and download it as a file.
- 📱 **Responsive Interface** — use the editor on desktop and mobile browsers.
- 🔒 **Local Processing** — save data is processed in your browser; the editor does not require uploading your save to a backend server.

> The web version is under active development. Feature availability and save compatibility should be verified before relying on edited saves.

## 🚀 How to Use

1. **Open the editor:** [justplguy.github.io/D2-Survivors-Save-Editor-Web](https://justplguy.github.io/D2-Survivors-Save-Editor-Web/)
2. **Load your save:** paste a save code beginning with `D2S1:` or load a supported save file.
3. **Choose a section:** edit gold, equipment, item modifiers, or skills.
4. **Review your changes:** use the preview before exporting.
5. **Generate the save code:** export the modified save code or save it to a file.
6. **Test your save:** load the edited save in the game and verify that everything works as expected.

### ⚠️ Important

**Always back up your original save before making changes.**

Test edited saves on a copy first. Incorrect or unsupported modifications may cause unexpected results or prevent a save from loading correctly.

## 🛠️ Technology

The web editor is built with:
